## 2. 插图分类

### 2.1 分类方法

对每张嵌入图像解码后计算两个结构特征，再结合图注差异：

| 特征 | 说明 |
|---|---|
| aHash | 16×16 均值哈希，反映整体明暗结构；差异率 = 汉明距离 / 256 |
| 灰度直方图 | 16 桶分布，反映明暗构成；差异 = 0.5×Σ|p−q| |
| 图注（去图号）相似度 | <0.45 直接判「信息变化」 |

| 判定 | 条件 |
|---|---|
| 像素完全一致 | 解码像素 sha256 相同 |
| 纯样式变化候选 | aHash 差异 ≤10% 且直方图差异 ≤0.10 |
| 信息变化 | aHash 差异 ≥30% 或直方图差异 ≥0.25，或图注已明显不同 |
| 无法判断 | 其余 |
