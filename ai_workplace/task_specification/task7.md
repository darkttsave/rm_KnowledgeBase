# 任务：RM 2026—2027 规则对比 · 阶段 C 补充核验

## 背景

阶段 C 已将 534 条正文变化候选归并成 62 个规则变更事件，完成了大模型语义分析。

本轮不重新执行阶段 A/B，也不重新分析全部正文。

目标是修正事件分类口径、补充特殊内容差异、处理证据问题，并生成适合人工审核的重点变更清单。

## 一、修正分类口径

1. 区分比赛规则变化与文档、排版变化。
2. `1.2 新赛季主要变更` 不计入实质新增比赛机制。
3. 场地图例补充应按实际内容判断，不直接计入新增机制。
4. 对机制重构事件，保留内部具体功能的新增、取消和修改，不以一个“重构”标签掩盖实际变化。
5. 保留原始 62 个事件及其对应的 B2 差异 ID，不覆盖历史判断。

## 二、补充特殊内容差异

1. 重新核对 B2 的表格对应关系，优先使用表题、上下文和规则主题，不依赖表号直接匹配。
2. 对重要表格核对行列关系、数值、单位及适用对象。
3. 将表格中发现的实质规则变化关联到已有事件，或建立新的变更事件。
4. 对像素不同的插图进行分类，区分纯样式变化、信息变化和无法判断。
5. 对影响比赛机制的场地图纸、流程图和公式，提供可供人工查看的新旧页面对照。
6. 不得因为表格或图片的自动检查通过就宣布其语义完全一致。

## 三、清理未决问题

1. 对 5 个“证据不足”事件保留逐条差异记录，不得因合并而隐藏未解决的问题。
2. 对 18 个待人工核验事件和涉及重大数值、机制变化的事件，整理明确的审核理由。
3. 检查否决的 24 对错误配对，确认其对应差异已进入正确的新增、删除或其他候选中。
4. 查明阶段 C 原始来源回查率 99.2% 的所有例外，逐条解释或修正。
5. 对空中系统、雷达、哨兵等旧机制迁移问题，不得把局部文字继承直接等同于整个机制保留。

## 四、输出

保留原阶段 C 产物，新建补充核验结果。

需要：

1. `规则变更候选_修订版.jsonl`
2. `特殊内容核验报告.md`
3. `未解决争议清单.md`
4. `重点规则人工审核表.md`
5. `阶段C补充核验质量报告.md`

重点规则人工审核表应优先按机器人、比赛机制、场地、判罚等类别分组。

每条应包含：

- 变化主题；
- 2026 原文与来源；
- 2027 原文与来源；
- AI 判断；
- 尚需核实的疑点；
- 是否可能影响机器人设计或比赛策略。

不要要求人工直接审核全部原始技术差异。

## 五、边界

- 保留阶段 A/B/C 原始产物，不覆盖。
- 不进行模型训练或多模型评测。
- 不重新开发 PDF 解析器。
- 不把未经人工确认的候选事件标记为最终事实。
- 不生成最终队内学习笔记。

完成后停止，等待上游审核和人工介入。
