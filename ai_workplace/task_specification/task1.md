# 任务：RM 2026—2027 规则 PDF 预检查

## 背景

我们准备比较 RMUC 2026 V2.2.0 与 RMUC 2027 V1.0.0 的规则差异。

当前仅执行阶段 A 的预检查，不进行规则内容对比或 AI 总结。

## 工作要求

1. 检查运行环境，优先复用成熟 PDF 处理工具（PyMuPDF、Poppler 等），不要自行开发 PDF 解析器。缺少必要依赖时，在独立虚拟环境中安装。
2. 对两份官方原版 PDF 记录文件名、版本、物理页数和 SHA256。
3. 检查能否提取内置目录书签、正文、页码与文本布局信息。
4. 对普通正文、目录、复杂表格、特殊字体页面进行抽样检查。
5. 检查是否存在乱码、文本错序、表格结构破坏等问题。
6. 如果提供了个人批注版，单独检查批注能否提取，不将个人笔记混入官方规则正文。
7. 给出后续全文解析方案，包括推荐工具、已知风险和需要人工检查的内容。

## 约束

- 原始 PDF 只读，不进行修改。
- 优先使用成熟库，避免重复造轮子。
- 不进行全量 OCR，除非发现具体页面确有需要。
- 不使用 LLM 猜测或补全无法识别的规则原文。
- 本阶段不进行章节差异分析，不建立 RAG 知识库。

## 输出

生成一份简洁的《PDF预检查报告.md》。

报告需说明：
- 两份 PDF 的基本信息；
- 当前环境采用的解析工具；
- 文本与表格提取质量；
- 发现的异常及对应页码；
- 是否具备进入全文结构化处理阶段的条件。

完成后停止，等待人工审核，不自动进入下一阶段。
