# 任务：RM 2026—2027 规则对比 · 阶段 C 语义分析与差异收敛

## 一、背景

阶段 A、B1、B2 已完成。

B2 输出了 1333 条候选差异记录，并建立了正文、表格、公式和图示的覆盖清单。

本轮开始使用大模型分析规则变化的实际含义。

目标不是重新执行文本 Diff，而是将候选差异整理为有证据支持、可供人工审核的规则变更事件。

## 二、执行原则

1. 复用 B2 的候选差异、章节映射、结构化 JSONL 和官方 PDF。
2. 按章节及主题分批组织大模型输入，不一次性提交全部差异。
3. 检索上下文时优先提供完整相关条款、条件、例外和表格。
4. 必须实际使用 LLM 完成语义判断，不能仅将规则匹配或相似度计算包装成语义分析。
5. 不得让 LLM 补写不存在的规则原文或编造引用。
6. 保留全部 B2 原始记录，不覆盖上游资产。

## 三、核心工作

### C1：配对复核

重点重新检查：

- 41 对低相似度推测配对；
- 185 条删除候选；
- 109 条新增候选；
- 13 个 B1 待核验的章节映射。

允许重新搜索其他章节的相关规定。

对明显错误的配对进行纠正，并保留原配对及修改依据。

### C2：LLM 语义分类

按照规则实际含义判断：

- 实质新增；
- 实质取消；
- 规则修改；
- 规则继承或迁移；
- 机制重构；
- 仅表述调整；
- 证据不足，暂无法判断。

分析时重点检查适用对象、触发条件、限制、例外、数值与效果。

每条结论必须保留 2026、2027 双方相关证据及 record_id；真正单侧新增或取消的候选，也要记录另一赛季的检索范围和未找到对应规则的情况。

### C3：差异收敛

将属于同一规则机制的多个句段差异合并为规则变更事件。

每个事件保留：

- 变更 ID；
- 规则主题；
- 新旧规则内容及引用；
- 变更类型；
- 对应的 B2 差异 ID；
- AI 判断依据；
- 证据充分性；
- 核验状态。

不得因合并而丢失原始差异信息。

### C4：特殊内容

- 对涉及具体参数的表格差异，必须回查 source_text_lines 和必要的 PDF 页面。
- 对公式变化，必须确认分式、上下标及变量含义。
- 对不同的场地图纸、机制图示，允许利用视觉能力辅助判断。
- 图像未能核实时保留待确认状态，不作确定结论。
- 不将模型的工程推测写成官方规则事实。

## 四、输出

1. `规则变更候选.jsonl`：按规则事件组织的机器可读结果。
2. `规则变化初步总览.md`：按机器人、场地、机制、比赛流程、判罚等主题汇总。
3. `语义分析争议清单.md`：错误配对、迁移不明、证据不足、特殊内容待确认事项。
4. `语义分析质量报告.md`：说明模型、Prompt、检索范围、处理覆盖率、变更数量和未决事项。

请保留所使用的模型名称、配置与 Prompt，确保分析过程可复现。

## 五、边界

- 不覆盖阶段 A、B 的原始数据。
- 不进行模型训练或多模型评测。
- 不将模型输出自动标记为人工已确认。
- 不直接生成最终队内规则学习笔记。
- 不为完成任务而强制消除所有不确定性。

完成后停止，等待上游审核与人工确认。
