## 2. 对齐方法

### 2.1 程序生成候选（可复现）

脚本：`ai_workplace/tools/40_align_candidates.py`，产物：`alignment/align_candidates.json`。

1. **章节特征**：标题（去掉编号）字符二元组集合；正文（段落 + 表格单元格 + 表/图题）字符二元组计数。
2. **相似度**：标题 Jaccard、正文余弦；组合分 = 0.45×标题 + 0.40×正文 + 0.10×编号先验 + 0.05×层级。
3. **条款级路由**：把每个 ≥10 字的条款按二元组包含度路由到最相似的对方章节（阈值 0.6），得到**份额矩阵**。这是区分「合并/拆分」与「找不到」的关键证据：
   - 单个 2026 章节的条款被多个 2027 章节吸收 → 拆分线索；
   - 单个 2027 章节吸收多个 2026 章节的条款 → 合并线索；
   - 条款 0 命中 → 疑似删除；新章节 0 来源 → 疑似新增。
4. **自动匹配**：标题去编号后完全相同的，直接判为「保留」（107 对）。

### 2.2 语义裁断（LLM 辅助，依据全部落盘）

脚本：`ai_workplace/tools/43_align_build.py` 中的 `MANUAL` 决策表。对程序无法定论的 45 个章节，逐条依据下列证据裁断，并把依据写进 `evidence` 字段：

| 证据类型 | 含义 | 标记前缀 |
|---|---|---|
| 正文对照 | 直接比对两节正文/表格 | `D:` |
| 关键词命中 | `42_search.py` 统计某术语在两份文档中的出现次数与所在章节 | `S:` |
| 候选分数 | 相似度与路由份额 | `C:` |
| 程序匹配 | 标题完全一致 | `P:` |
| 变更说明 | 2027 §1.2「新赛季主要变更」的表述 | `M:` |

**没有使用**「旧编号不存在 → 删除」「新标题首次出现 → 新机制」这两条捷径。例如 2027 `3.1 机器人`/`3.2 组合系统`/`3.3 附属设备` 三个新编号被判为「层级容器（疑似新增）」而非新机制，因为其正文为空、子节分别对应 2026 的既有章节。

## 4. 关键结论（结构层面）

1. **章级结构基本稳定**：1–9 章一一对应，仅附录由 3 个减为 2 个（雷达信息波特性附录疑似删除）。
2. **第 3 章被重组**：2026 的 7 个机器人类型（L2）重组为 2027 的 3 个容器（机器人/组合系统/附属设备，L2）+ 7 个具体类型（L3）；其中英雄机器人 + 工程机器人合并为重装机器人，并把「自定义客户端」从第 5 章迁入成为「自定义终端」。
3. **第 5 章变化最大**：新增 5.2 自适应装甲机制、5.6.2 战场控制机制；英雄/工程机器人特殊机制（5.6.1、5.6.2）与「重装机器人」合并后由 5.7.1 承接，空中机器人特殊机制（5.6.3）无对应章节，5.6.7 能量机制与 5.1.5.5 激光检测模块离线亦无对应；其余章节因插入而整体顺延编号。
4. **场地章节**：新增制高点、机库平台；取消停机坪、飞行区；飞坡改名隧道；梯形高地增益点迁移到新建的制高点。
5. **违规与判罚**：条款重编号幅度大（R 编号不可作为对应依据）；2026 的「空中机器人」+「其他机器人」合并为 2027 的「组合系统」。

## 5. 局限与风险

1. **「疑似删除」不是结论**。B1 只对齐章节；`空中支援`、`部署模式`、`底盘能量`、`激光检测模块`、`频谱/空口/调制` 等机制在 2027 全文检索 0 命中，因此暂判为疑似删除 / 疑似取消，但**是否真废弃需 B2 逐条正文比对确认**（可能被改写为其他表述）。
2. **合并类对应只到章节层**。例如「重装 = 英雄 + 工程」在章节层成立，但内容层只有工程的 50% 防御条款被继承、英雄的部署模式未检出；这类差异留给 B2。
3. **容器节判定**：2027 新增的 3 个空章节（3.1/3.2/3.3）判为「层级容器（疑似新增）」，若后续需要按「机制新增」统计，应把它们排除。
4. **编号顺延量很大**（44 个单元）。这不是规则变化，做差异分析时**必须先按本映射对齐，再比对正文**，否则会产生大量假差异。
5. **相似度阈值是启发式**。程序候选与条款路由只用于定位；最终对应由逐条证据裁断，每条结论都能追溯到具体的文本或检索命中数。
6. **2027 §1.2 只作佐证**。该节明确给出合并/改名/取消的清单，本报告用它交叉验证，但所有对应关系都由正文/检索证据独立支持，没有单靠它下结论。
7. **范围外**：未对表格、公式、流程图做语义比对；未做任何正文差异结论；未修改阶段 A 数据。
