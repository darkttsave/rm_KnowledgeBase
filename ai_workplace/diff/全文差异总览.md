## 4. 检测方法（可复现）

1. **段落缝合**：阶段 A 有个别段落被拆成多条记录（续行判断未命中），直接比对会把「一段改写」误报成「1 删除 + 1 新增」。因此先按「上一条未以句末标点结束且下一条不是新列表项」的规则把同一章节内的连续正文记录重新拼接，再切句。
2. **章节内配对**：以 B1 对齐单元为范围，句子级字符相似度 ≥ 0.60 做一对一贪心配对；对同章节两侧的残余句再做一次低阈值（二元组 Jaccard ≥ 0.20）的**推测配对**，标 `tentative_pairing` 并强制进入待核验。
3. **全文兜底**：所有未配对的残余句在全文中检索（阈值 0.80、长度 ≥ 12 字），找回跨章节迁移/重组；仍找不到的才列为新增/删除候选。
4. **分类规则**：文本完全一致 → 内容一致；只有列表项编号/条款编号变化 → 编号变化（不计内容变化）；只有交叉引用编号变化 → 引用编号更新（不计内容变化）；数字或单位集合变化 → 实质修改候选；相似度 ≥ 0.90 → 文字调整候选；其余 → 实质修改候选。
5. **不许判定**：新增/删除候选一律标 `needs_review`，并在 `evidence` 中附带「全文最高相似度 / 最相似章节」，供人工复核。
